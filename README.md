# ArtisanGo

Application mobile de mise en relation entre clients et artisans locaux.

ArtisanGo permet aux clients de rechercher des artisans et leurs services,
consulter les informations disponibles, publier des avis, gérer leurs favoris
et contacter directement les artisans.

Les artisans peuvent également publier leurs services avec une description,
une photo, une ville et une localisation.

## Fonctionnalités

- Authentification des utilisateurs
- Recherche et filtrage des services
- Gestion des services proposés par les artisans
- Système d'avis et de notation
- Gestion des favoris
- Géolocalisation des services
- Contact des artisans via WhatsApp
- Partage des services
- Mode sombre
- Support du français et de l'anglais

## Technologies utilisées

- Flutter / Dart
- Firebase Authentication
- Cloud Firestore
- Cloudinary
- Geolocator / Geocoding
- SharedPreferences
- Easy Localization

## Architecture

Le projet est organisé autour de plusieurs composants afin de séparer
l'interface utilisateur, les modèles de données et les services utilisés
par l'application.

Les principales parties du projet sont organisées dans le dossier `lib/`,
notamment les écrans, widgets, modèles et services.
